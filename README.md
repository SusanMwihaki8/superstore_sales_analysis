# Superstore sales analysis
A retail data analysis project exploring sales performance and profitability using Python aiming at identifying business patterns and provide data-driven recommendations to support better decision-making.
##Objectives
1. Analyze sales performance across different regions.
2. Examine monthly sales trends over time.
3. Investigate relationship between discounts and profit.
4. Identify product categories and subcategories with potential profitability issues.
5. Recommend ways to improve sales performance.
##Tools and Technologies
- Python: for data analysis.
- pandas: for loading and manipulating data.
- Matplotlib: for data visualization.
- Visual Studio Code: the development environment.
##Key Analysis and Findings
1. Sales Performance by Region
A bar chart was used to compare sales across regions.
2. Monthly Sales Trends
A line chart was created to examine how sales changed over time.
3. Discounts and Profitability
Correlation analysis showed an approximate discount-profit correlation of -0.22, indicating a weak negative relationship.
##Business Recommendations
- Review discount strategies to understand their effect on profitability.
- Investigate loss-making categories and sub-categories before changing pricing.
- Monitor sales trends over time to support planning.
- Compare regional performance to identify opportunities for improvement.
##Skills Demonstrated

- Exploratory data analysis
- Correlation analysis
- Data visualization
- Business insight generation
